Rail Fence Cipher (Transposition Technique)
Problem Statement: Design and implement a program in Java/Python to demonstrate the Rail Fence (Zig-Zag) transposition cipher.
The program should accept a plaintext string and a key k (number of rails), encrypt the message by writing characters diagonally in a zig-zag pattern and reading off row-by-row, and subsequently decrypt the resulting ciphertext back to its original plaintext.
Input: Plaintext: "DEFEND THE EAST WALL",
Depth (k): 3
Output: Ciphertext: "DTEWEENEAASTFLHDTL"
